## 自分のプロフィール

### 仕様

- アイコンタップでアイコン写真拡大
- フォロー中、フォロワーボタン
  - タップすると自分がフォローしているユーザの一覧に飛べる（フォロワーも同様）
- 右上の三点リーダーから詳細設定画面に遷移する
- ユーザ情報の表示
  - ユーザ名、性別、身長などを表示
  - 右上の詳細設定画面からユーザ情報の入力が行える
- タブで表示する投稿の内容を変更できる
  - 自分の投稿、お気に入りに登録した投稿で切り替えができる
- 投稿の表示列の変更ができる
  - 1, 2, 3列まで変更が可能
  - 3列の場合はユーザの詳細情報は表示されず写真のみ（スマホの場合、文字が小さく見えづらい状況を避けるため）
- 投稿に三点リーダをつける
  - 自分の投稿の場合、編集画面に遷移できる

## 相手のプロフィール

### 仕様

- 自分のプロフィール情報とほぼ同様
- 表示される投稿のタブ切り替えが行える
  - 相手ユーザの投稿一覧
  - 相手ユーザがフォローしている相手の投稿をランダムで表示する
- 右上の三点リーダ
  - 通報、非表示、ブロックなどが行える
- 投稿の三点リーダー（相手の投稿の場合）
  - 通報、ブロック、非表示などが行える
- 「相談を申し込む」ボタン
- 「フォロー」ボタン

## プロフィール編集

### 仕様

画面上部の「保存」ボタンで保存する。

| 項目 | 必須 | 補足 |
| --- | --- | --- |
| プロフィール画像 | 任意 | 「変更」から設定 |
| 名前 | **必須** | |
| 性別 | 任意 | 未設定あり。選択肢は下記 |
| 身長 | 任意 | 未設定あり |
| 年代 | 任意 | 未設定あり。選択肢は下記 |
| 骨格タイプ | 任意 | 未設定あり。選択肢は下記 |
| パーソナルカラー | 任意 | 未設定あり。選択肢は下記 |

- 入力変更が完了したら保存ボタンを押し保存
- 「名前」は `@ユーザ名` とは別の、自由に付けられる表示名
  - 新規会員登録では名前を聞かないため、登録時はユーザ名を初期値にする（**暫定**）。プロフィール編集で変更できる

### 選択肢

| 項目 | 選択肢 | 管理方法 |
| --- | --- | --- |
| 性別 | 男性 / 女性 / その他 | アプリ内で固定 |
| 年代 | 10代 / 20代前半 / 20代後半 / 30代前半 / 30代後半 / 40代 / 50代以上 | アプリ内で固定 |
| 骨格タイプ | ストレート / ウェーブ / ナチュラル | DBのマスタテーブル |
| パーソナルカラー | イエベ春 / ブルベ夏 / イエベ秋 / ブルベ冬 | DBのマスタテーブル |

- いずれも任意で、未設定を選べる
- 年齢は数値ではなく年代で保存する（年齢の数値だと、時間が経つと古くなるため）
- 年代の区分は検索の「年代」と共通（`search.md` 参照）
- 骨格タイプ・パーソナルカラーは、後から選択肢を追加できる。使わなくなった選択肢は削除せず非表示にする（設定済みのプロフィールが壊れないようにするため）

> **画面画像との違い**
> `design/EditProfile.png` では「年齢」と表示しているが、実装では「年代」の選択式になる。画面画像の作り直しが必要。

## フォロー中一覧

### 仕様

- 自分がフォローしているユーザの一覧が見れる
- 画面上部に「フォロー中」という文字とフォロー数を設置
- 「フォロー中」という文字の下にユーザの検索欄を設置する
- 相手ユーザの表示情報
  - ユーザ名、身長、性別など、相手ユーザがプロフィールに登録した情報の一部が表示される
  - フォローしたタイミングが簡単に分かる（2時間前、3日前、1ヶ月前、1年前など）
- フォロー解除ボタンの設置
  - 押すと「フォロー」という文字に変わる
- 相談するボタンの設置
  - 押すと「申請済み」に変わる
- 並び替え機能
  - フォローの新しい順、古い順で並び替えが行える

### フォロー解除の扱い（重要）

- フォロー関係のテーブルに「解除日時」を持つ
- フォロー中一覧は、有効なフォローと「解除から5分以内」のものを返す
- 解除から5分以内の再フォローは通知を飛ばさない

> 押し間違いで消えてしまうのを防ぐための仕様。フォロー関係は物理削除せず、解除日時を持たせて論理的に扱う。
