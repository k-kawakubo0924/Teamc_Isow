## 仕様

### アプリタイトル

- 「ISHO」を画面上部に表示する

### 通知

- 左上のマークから通知一覧画面に遷移する

### 新着メッセージ

画面上部に、DM の新着メッセージを表示する。

- 送信者のユーザ名
- 経過時間（例：3分前）
- メッセージ本文（省略表示）
- 未読件数バッジ
- 「すべて見る」から DM 一覧へ遷移する

### ファッション投稿表示

タブの切り替えで表示する内容を変更する。

| タブ | 表示内容 |
| --- | --- |
| おすすめ | おすすめファッション一覧 |
| フォロー中 | フォロー中ユーザの投稿一覧 |
| 新着 | 新着投稿一覧 |

#### 並び順

| タブ | 並び順 |
| --- | --- |
| おすすめ | いいね数の多い順 → 同じなら投稿日時の新しい順（**暫定**） |
| フォロー中 | フォロー中ユーザの投稿を、投稿日時の新しい順（解除から5分以内のフォローは含めない） |
| 新着 | 投稿日時の新しい順 |

- おすすめの並び順は、選定ロジックが決まるまでの**暫定**。いいね数を表示のたびに集計しているため、投稿数が増えたら `posts` にいいね数を持たせる方式に切り替える
- 一覧は20件ずつ取得する（1回の上限は50件）
- フォロー中タブに投稿がない場合、誰もフォローしていなければ「フォロー中のユーザーがいません」、フォロー中のユーザーに投稿がなければ「フォロー中のユーザーの投稿はまだありません」と表示する

#### 読み込み方式

- 無限スクロール（一覧の末尾が近づいたら次の20件を読み込む）
- 読み込みに失敗した場合は自動ではやり直さず、「もう一度読み込む」ボタンを表示する
- 途中で投稿やいいねが増えると次のページに同じ投稿が含まれることがあるため、すでに表示している投稿は表示しない

### 投稿一覧の表示項目

- 投稿写真
- ユーザ名
- 身長
- いいねボタン（いいね数を表示）
- お気に入りボタン

### いいねとお気に入りの違い

| | いいね | お気に入り |
| --- | --- | --- |
| 意味 | 投稿者への反応 | 自分が後で見返すための保存 |
| 公開範囲 | 件数が公開される | 自分だけが見る。他人には見えない |
| 一覧 | — | 自分のプロフィールの「お気に入り」タブに溜まる（`profile.md` 参照） |
| テーブル | `likes` | `favorites` |

- 性質が異なるため、テーブルは `likes` と `favorites` に分ける

### 表示列の切り替え

- 1列 / 2列 / 3列 に切り替えられる（既定は2列）
- 表示列を1列・3列に変更した場合は、投稿者名・身長・いいね／お気に入りボタンなどは記載せず写真のみにする（3列は `profile.md` と同じ。詳細を表示するのは2列のときだけ）
- 選んだ表示列は**端末ごとに記憶**し、次回開いたときも同じ列数で表示する（**暫定**）
  - ブラウザ（localStorage）に保存する。見やすい列数はスマホと PC など画面の大きさで変わるため、サーバー（アカウント）には保存しない
  - 保存できない環境（プライベートブラウズなど）では、毎回2列で表示する

### 下部ナビゲーション

ホーム / 検索 / 投稿 / DM / プロフィール の5つ。DM には未読件数のバッジを表示する。
