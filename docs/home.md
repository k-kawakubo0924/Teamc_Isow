---

## 仕様

### アプリタイトル

- 「ISHO」を画面上部に表示する

### 通知

- 左上のマークから通知一覧画面に遷移する

### 新着メッセージ

画面上部に、DM の新着メッセージを表示する。

- 送信者のユーザ名
- 経過時間（例：3分前）
- メッセージ本文（省略表示）
- 未読件数バッジ
- 「すべて見る」から DM 一覧へ遷移する

### ファッション投稿表示

タブの切り替えで表示する内容を変更する。

| タブ | 表示内容 |
| --- | --- |
| おすすめ | おすすめファッション一覧 |
| フォロー中 | フォロー中ユーザの投稿一覧 |
| 新着 | 新着投稿一覧 |

### 投稿一覧の表示項目

- 投稿写真
- ユーザ名
- 身長
- いいねボタン（いいね数を表示）
- お気に入りボタン

### 表示列の切り替え

- 1列 / 2列 / 3列 に切り替えられる
- 表示列を1列に変更した場合は、投稿者名・身長などは記載せず写真のみにする

### 下部ナビゲーション

ホーム / 検索 / 投稿 / DM / プロフィール の5つ。DM には未読件数のバッジを表示する。

- 「新着」の並び順（投稿日時の降順を想定）
- 一覧の読み込み方式（無限スクロール／ページング／件数）
- 未ログイン状態でホーム画面を閲覧できるか
- 表示列の設定を記憶するか（次回起動時も同じ列数か）
- いいねとお気に入りの違い
