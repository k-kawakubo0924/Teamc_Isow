# ISHO 仕様書

ファッション相談アプリ「ISHO」の機能別仕様書です。
Notion の「画面設計」ページを機能ごとに分割したものです。

## ファイル一覧

| ファイル | 内容 |
| --- | --- |
| `auth.md` | ログイン・新規会員登録 |
| `home.md` | ホーム画面（投稿一覧） |
| `search.md` | 検索 |
| `post.md` | 投稿 |
| `notification.md` | 通知 |
| `dm.md` | DM・相談 |
| `profile.md` | プロフィール・フォロー |
| `settings.md` | 詳細設定・お問い合わせ |
| `admin.md` | 管理者画面 |

## 画面画像との対応

画面の完成例は `design/` に配置しています。各仕様書の冒頭に、対応する画像ファイル名を記載しています。

## 記法について

- **仕様** … Notion の画面設計に記載されている内容
- **未確定・要確認** … 画面設計からは判断できず、実装前に決める必要がある項目

「未確定・要確認」は仕様ではありません。チームで決定した内容を「仕様」側に移してから実装に進んでください。
