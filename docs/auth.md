## ログイン

### 仕様

- 基本情報入力
  - メールアドレス
  - パスワード
- 新規会員登録ボタン
- ログインボタン
  - 入力情報が不一致の場合、警告文を表示する

### 未確定・要確認

- ログイン状態の保持期間（何日でログアウトされるか）
- パスワードを忘れた場合の導線（ログイン画面に「パスワードを忘れた方」は無いが、詳細設定のパスワード再設定はログイン後の機能）
- ログイン成功後の遷移先（ホーム画面を想定）

## 新規会員登録

### 仕様

- 基本情報入力
  - メールアドレス
  - 電話番号
  - パスワード
  - ユーザ名
- 記入項目確認ボタン
  - 入力情報がすでに登録されている場合、警告文を表示する
  - 入力形式が異なる場合、警告文を表示する
- 入力規則（実装時に暫定で決定。正式に決まり次第ここを更新する）
  - ユーザ名 … 一意とする。先頭の `@` はDBに保存せず、表示時に付ける
  - 電話番号 … ハイフンなしで保存し、重複は許す

### 未確定・要確認

- 各項目の入力規則
  - パスワード … 詳細設定のパスワード再設定画面では「8文字以上、英字と数字を含めてください」と表示されている。新規登録も同じ規則か
  - ユーザ名 … 画面上は `@haru_st` のような表記。使用可能な文字は何か（一意かどうかは仕様に暫定で記載）
  - 電話番号 … 入力時にハイフンを許すか（保存形式と重複可否は仕様に暫定で記載）
- メールアドレスの確認メール送信の有無（メールアドレス再設定画面には「入力したアドレスに確認メールを送ります」という記載がある）
- 登録直後のプロフィール（性別・身長など）の入力タイミング
  - プロフィール編集画面では「名前」のみ必須で、他は「未設定」から始まる
