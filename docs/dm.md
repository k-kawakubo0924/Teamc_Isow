## 仕様

### DM一覧

- 上部に「メッセージリクエスト」への導線を設置し、件数を表示する
- 上部の検索欄からユーザの検索が行える
- やり取り中のユーザは、上からやり取りを最後に行った順に並べる
- 未読のメッセージ数がメッセージ一覧の一番右側に表示される
- 各行に表示する内容
  - ユーザ名
  - 経過時間（例：3分前、1時間前、昨日、2日前、5日前、2週間前）
  - 最新メッセージの本文（省略表示）
  - 状態ラベル（「終了」など）
- 下の「送信したリクエスト」から、自分が申請したリクエストの一覧が表示される

### チャット画面

- 画面上部に相手のユーザ名とアイコンを表示する
- メッセージを入力して送信できる
- ＋ボタンから画像の送信が行える
- 各メッセージに送信時刻を表示する
- 右上のハンバーガーメニューから以下が行える
  - 通報
  - ブロック
  - 会話終了

### 追加機能

- メッセージのピン留め機能
- 通知オフ機能
- 一か月連絡を取っていなかったら自動的に会話終了

### 相談の申し込み

- 相手のプロフィールの「相談する」ボタンから申し込む
- 押すと「申請済み」に変わる（`profile.md` 参照）
- 相談が届くと、相手に通知が飛ぶ（`notification.md` 参照）

## 未確定・要確認

- 相談申し込みとメッセージリクエストの関係
  - 「相談する」を押すとメッセージリクエストとして相手に届く、という理解で合っているか
- リクエストの承認・拒否のフローと画面
- 会話の状態（申請中／進行中／終了）の一覧と、状態が変わる条件
- 会話終了後にできること（閲覧のみか、再開できるか）
- 「一か月連絡を取っていなかったら自動的に会話終了」の判定タイミング（定期実行が必要）
- ピン留めの対象（メッセージ単位か、会話単位か）と上限件数
- 通知オフの単位（会話ごとか、DM全体か）
- ブロックした場合の挙動（相手からの表示、既存の会話の扱い）
- 通報の送信先と、その後の処理
- 送信できるメッセージの種類（テキスト・画像のほか、動画も送れるか。チャット画面には「画像・動画」の表記がある）
- 既読表示の有無
